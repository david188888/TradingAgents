## Why most of §2.3 is a triage task, not a port

This fork has diverged structurally from upstream on exactly the paths §2.3
targets: there is no `agents/utils/rating.py`, no `backtest.py`, no
`agents/trader/` or `agents/risk_mgmt/` subgraph, no reflection chain, and the
decision-memory write side was retired. Porting those commits would mean
**re-introducing retired code**, not fixing a bug. Each slice therefore carries
a verdict: `already-covered` / `partially-covered` / `not-covered` /
`not-applicable`.

## SEC EDGAR: plan B instead of the sub-project

The handoff's §2.6 proposes a six-step SEC EDGAR sub-project. Investigating it
found the current state is *honest but misleading in effect*:

- `tradingagents/research/official_disclosures.py` returns
  `outcome="not_supported"`, `reason_code="official_filings_provider_not_implemented"`
  for `market == "global"` without making a request, and the Reader shows
  "unavailable: official_disclosures". Nothing is faked.
- But `official_disclosures` is planned as a **required** capability for global
  medium/long, so the default `horizon="medium"` forced every US
  `company_research` run to `forced_research_rating="insufficient_evidence"`.
  The reader saw "insufficient evidence", not "SEC is not wired up".

Downgrading the capability to `optional` in `horizon_policy` was rejected: it
breaks `test_required_capability_matrix_is_market_invariant`, a deliberate
invariant that the *required* capability set does not depend on the market.
Instead the closure now distinguishes a provider this fork has deliberately not
built from one that was tried and failed:

- `eligibility._is_unimplemented_provider()` reads the capability result's
  reason codes (`official_filings_provider_not_implemented`).
- Such a capability still yields `decision_eligibility == "limited"`, still
  appears in `missing_capability_actions`, and still raises the
  "recheck official_disclosures when provider or filing is available" review
  trigger — it just no longer forces the rating.

The full sub-project (transport, CIK identity, submissions discovery, raw
staging, evidence closure, reader projection) remains **not built**. It is worth
its own decision later; the value is US-only, and this fork is A-share first.

## Boundaries preserved

- A-share-first vendor order and source labels: untouched. The one router-facing
  change (typed provider failures) was verified to keep `mootdx → tushare`
  ordering with `yfinance`/`alpha_vantage` still market-filtered.
- Evidence semantics: `PASS` / `LOW_CONFIDENCE` / `FAIL_STOP` unchanged; an
  unobservable window is reported as unavailable, never as absence, and never as
  bearish evidence.
- OHLCV policy: no gap filling; incomplete rows are dropped and an unsettled
  latest bar still errors.
- research-only product boundary: no orders, sizing, P&L ranking, or execution.
