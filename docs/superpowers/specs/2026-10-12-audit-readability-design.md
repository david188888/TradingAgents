# 审计中心阅读整理

- **Status: Historical** — Do not use this document as evidence of current implementation behavior.
- 已实施的阅读行为见[Reader架构](../../architecture/research-reader.md)，重试边界见[运行观测](../../operations/observability-replay.md)。
- 用户已批准：默认展示研究可用性、失败位置与原因、资料缺口；技术记录收进独立入口；环节详情移除执行统计。

## 范围与职责

审计中心默认进入「研究检查」，通过已有只读研究记录与过程 API 回答：有没有已发布报告、报告有哪些质量限制、哪些环节失败或未执行、有哪些已记录的资料问题。未发布不代表没有资料；技术摘要可用不等于研究结论可用。旧运行缺少记录时明确显示无法判断。

「技术排查」按钮切换到原有六分区，保留调用统计、角色、能力、工具、文件与配置的按需读取；默认页面不展示 SDK、预算授权、文件计数和内部序号。已有技术深链接保持有效，关闭与窄屏详情的焦点返回不变。隐藏区域不能留在键盘遍历中。

主面板环节详情保留研究输入、真实保存内容及发布局限，移除执行统计。安全公开的失败类别可用于解释失败；仅投影已失败环节的最终诊断，禁止泄露模型原响应、提示词、异常文本或隐藏文件。修复后成功的诊断不能继续显示为当前失败。

## 重试核查与修复边界

只读检查600418最新运行的冻结策略、预算、诊断与时间线，保留所有历史文件。整轮300秒时限耗尽不能继续重试，也不自动重跑付费研究。若发现订阅客户端将提前发生的传输错误误标为总时限耗尽，则保持明确分类，接入已有2/5/10秒有限重试；权限、额度、协议、不完整流、总时限耗尽仍不重试，不改变冻结预算或旧运行恢复策略。

## 验收

失败未发布、完成但低置信度、历史记录缺失、读取失败、刷新与切换运行均有明确状态。技术页面需显式打开，深链接可用；Escape、键盘焦点和手机布局继续有效。验证订阅短暂传输错误与总时限、永久错误之间的重试边界，执行相关Python/Vitest/浏览器检查、文档检查、Ruff、前端安装/类型检查/构建，包含生成资产。
