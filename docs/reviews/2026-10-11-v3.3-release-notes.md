# TradingAgents v3.3.0 — 统一公司研究与流程画布

- **Status: Historical** — Do not use this document as evidence of current implementation behavior.
- 发布范围：v3.2.0 之后的统一公司研究、一轮证据质询与 Reader 流程改进。Python 包、前端 package 与 lockfile 版本统一为 3.3.0。

## 新增与改进

- **统一公司研究**：新建 Web 单公司与批量研究固定使用 V7 公司研究，围绕经营质量、当前估值、事件影响与市场背景形成投资吸引力判断，无需选择研究模式或辩论轮数。
- **一轮定向质询**：三个专项先独立提出证据绑定的假设，独立挑战与代码核查后，被质疑专项各回应一次，再形成综合判断。没有目标质疑时不调用回应；修改或撤回的原观点退出结论支撑。
- **可追溯的投资判断**：保存四维判断、支持与反对理由、原始推翻条件、各项质疑的回应和裁决。证据不足、回应缺席及关键风险未解决仍限制结论，不用模型文字替代资料资格。
- **研究流程画布**：共同输入、专项分工、汇合、核查、回应、综合与发布有明确依赖连线。桌面详情相邻展开，窄屏纵向展示；键盘选择、重复点击和关闭返回焦点可用。
- **真实状态与动效**：执行完成和产物发布分别展示。失败或取消后停止动画，并明确显示“提议已保存但未发布 / 后续未执行”；记录读取失败提供只读重试。运行中的对应节点与箭头有轻量动效，支持减少动态效果偏好。
- **关注点读取修复**：补充回应页面读取支持 V6/V7，保留运行、流程版本与事件边界校验；补充关注点仍在独立基础研究保存后处理。

## 兼容与发布范围

旧 V1–V6 记录保留原版本的读取与恢复语义。Reader 使用已保存公开研究字段，读取不重新取数或调用模型。代码核查与发布的两个展示位置共享一个角色与一份统计，不代表两个执行实例。

本次发布 GitHub Release `v3.3.0` 及 GitHub 自动生成的源码归档，不发布到 PyPI。默认入口仍是仅绑定本机回环地址的 `tradingagents web`。
