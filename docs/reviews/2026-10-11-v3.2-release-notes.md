# TradingAgents v3.2.0 — ChatGPT 订阅、有限重试与 Reader 改进

Status: Release notes

本版本汇总 v3.1.0 之后合入 `main` 的订阅接入、原生模型重试与诊断、官方披露数字解析，以及 Reader 交互改进。Python 包、前端 package 与 lockfile 版本统一为 3.2.0。

## 新增与改进

- **ChatGPT 订阅接入**：通过官方 OAuth 授权并动态读取账户可用模型；单次及批量运行都绑定已授权账户。OAuth 凭据保存在本机受保护目录，不写入运行记录、浏览器配置或仓库。
- **完整 Responses 流处理**：只接受正常完成的 Responses 流；中断、不完整或提前结束的响应不会被保存成研究产物。目录可用不代表账户具有每项推理能力或权限。
- **有界的暂时错误重试**：普通 HTTP 408/429/5xx（含订阅请求）统一等待 2/5/10 秒，最多重试三次，并受每轮十二次模型尝试总上限约束。识别出的额度、权限、能力、协议错误与不完整流不会重试；可选 focus 仍只尝试一次。
- **持久化派发与安全诊断**：为重试预留持久预算，安全呈现模型错误。派发状态未知时不自动重放，避免重复请求或误算预算。
- **保守的官方 PDF 金额解析**：粘连的数字单元格无法可靠解释时拒绝猜拆，保留明确的数据缺口。
- **Reader 阶段查看**：打开阶段评审会滚动到内容并移动焦点；关闭后焦点回到触发按钮。键盘与移动端交互已验证。

## 兼容与范围

Web 是维护中的本地入口，新研究使用 `evidence_v1`。旧记录仍按原版本读取与恢复；读取已保存记录不会重新取数或调用模型。CLI 分析保留但不再维护。

GitHub Release 固定于 `v3.2.0` 并提供 GitHub 源码归档。2026-10-11 查询 PyPI 时 `tradingagents` 项目未找到；本次不发布 Python 包到 PyPI。

## 验证与限制

- 限定范围 Python 回归 886 项通过；随后订阅/重试定向套件 65 项通过，包含七项订阅临时 HTTP 与永久错误边界用例。
- Vitest 48 个文件、336 项通过；Playwright 24 项通过。
- `npm ci`、TypeScript 检查、前端构建、Ruff、Agent 文档链接检查及 Git 提交钩子通过。
- 本机 8000 工作台提供的 HTML 与构建产物一致，动态模型目录显示七个可选模型。
- GitHub 未配置 PR 检查或必需评审；未把缺少检查称为 CI 通过。

本次没有验证通过 ChatGPT 订阅完成一轮完整公司研究，也未验证研究准确率。历史 600418 失败/partial 记录保持原样，没有启动新的付费公司研究。

`npm audit` 仍报告现有依赖 18 项 advisories（4 moderate、12 high、2 critical）；环境中已有 mootdx 的 httpx/tenacity 版本声明冲突，前端构建提示有 chunk 超过 500 kB，测试仍有 Starlette 弃用警告。本版本没有升级无关依赖。
