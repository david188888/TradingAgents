# TradingAgents v3.0.0 — Web 统一证据研究

发布日期：2026-10-05。本页记录版本交付与升级边界；当前运行行为以
[Web 操作说明](../operations/evidence-research.md)、[架构](../../ARCHITECTURE.md)
及代码契约为准。

## 升级边界

Web 是持续维护的产品入口，使用 `tradingagents web --port 8765 --open`。
所有单项与批量新建采用 `evidence_v1`。显式请求旧 `classic` / `catalyst_v1`
新建或新运行重试返回 `410 research_profile_retired`；调用方应改用原生研究请求。
旧历史仍可阅读，合格中断任务保留原版本、身份及已消耗预算恢复。
CLI 分析代码保留，但不再维护；Web 启动命令继续支持。
本版本不改写用户记录、配置或凭据。

## 相比 v2.10.0 的主要变化

- **可用的统一研究流程**：公司研究、84 日催化研究和持仓复盘共享证据、
  假设、挑战、有界条件核查与分维度综合；批量支持 1–8 家公司。角色与预算
  由代码固定，移除旧模式、分析师预设和辩论深度控件。
- **合格来源与确定性估值**：纳入公开公司资料、新浪财务、巨潮有界正文与
  合格复权行情；V4 增加腾讯估值快照、Tushare PE/PB 历史及可重算的估值
  输入、哈希与证据引用。缺失或限流保持显式不可用；历史倍数的当前抓取
  不作为历史档案时点证明，单锚点参考区间不视为充分估值。
- **更清楚的结果页**：先看主判断、未解决风险和最多三条依据，再看估值、
  量化背景与下一步核查，细节按需展开。引用展示保存内容，阅读不取数、
  不调用模型；键盘、焦点恢复与窄屏布局经过验证。
- **可靠恢复与校验**：新工作流在既有一次有界修复内校验综合的维度引用，
  不降低发布门槛。旧工作流的采集、提示、恢复和 Markdown 行为保持兼容。
  自定义模型 ID 支持单项与批量；DeepSeek 可按实际任务覆盖推理投入，
  未配置任务继承原有全局设置。
- **文档与数据适配收尾**：包含 v2.10.0 后已经合入主线的共享证据核、
  有界核查、A 股来源修复及文档生命周期整理，不将历史方案当作当前功能。
