# TradingAgents v3.1.0 — 独立研究、证据 Reader 与成交量单位修正

Status: Release notes

本版本汇总 v3.0.0 之后已经合入主分支的功能，以及 a-stock-data v3.10.1 的相关最小修复。
Python 包与前端 package/lock 版本统一为 3.1.0。

## 新增与改进

- **V6 独立基础研究**：基础研究由研究模式定义，采集器和核心分析不读取可选关注点。独立基线持久化后才使用既有证据回答补充关注点；没有关注点时不增加补充调用。
- **证据 Reader**：展示独立结论、关键依据、最大疑点和下一步验证；证据侧栏/抽屉、研究过程与 Agent 产物可按引用追溯。读取保存报告不补取数据或调用模型。
- **V5 最小充分证据核查**：正式披露的数字提取、现金流桥、可选带日期机构 EPS 与同日候选同行报价支持有限检查。证据问题已回答与经济风险仍未解决分别展示。
- **DeepSeek 默认模型**：使用官方 `deepseek-flash` / DeepSeek V4.1 Flash，保留旧显式模型配置兼容；任务 effort 可选覆盖不改变默认投入。
- **腾讯 K 线成交量单位**：科创板股票 688/689 的日/周/月 raw/qfq 按股标注，其他股票按手；文本报告读取同一 provenance。保留供应商原始数值，不静默乘除 100。普通股票整手取整仍限制逐股精确对账。

## 兼容与范围

Web 仍是维护入口，新研究使用 evidence_v1；V6 是工作流版本，不是新的用户入口。
旧运行按其原版本、预算和证据身份读取/恢复，不重写历史数据或哈希。
本次不新增腾讯分笔、分钟线、期货或可转债的研究消费者。

Proma skill 已在本机单独原样升级固定 v3.10.1 并保全旧状态；它不是本仓运行依赖，也不会随此 Release 修改其他人的 Proma 安装。按需加载改造不在本次范围内。

## 验证与限制

Proma 的固定版本实跑 173 项离线测试通过、4 项联网测试跳过；另对四只证券做真实日线成交量与盘后包对账通过。
当前发布前检查结果补充在 [本次验收记录](2026-10-07-a-stock-data-v3101-acceptance.md)。

既有 npm 依赖审计仍有 18 项（包括 Vitest/tinypool 测试依赖的 2 项 critical），本次没有修改依赖解析或自动升级，审计不能称为通过。
