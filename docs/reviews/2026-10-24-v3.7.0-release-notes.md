# TradingAgents v3.7.0 — DeepSeek/Tavily 双路补证与证据版本

Status: Release notes

Python 包、前端 package 和 lockfile 根版本统一为 3.7.0。
通过 GitHub Release 与源码归档分发，不上传 PyPI 或额外二进制安装包。

## 用户可见变化

- 身份、简介和量化数据优先走专用接口；新闻、行业、政策和竞争材料由 DeepSeek Search/Fetch
  与 Tavily Search/Extract 配合发现。专用接口部分字段失败时，只补查缺失需求。
- 所有 Agent 共用最多三轮分析中补证；仅在取得合格增量后复核相关专项，最终综合执行一次。
  DeepSeek/Tavily Search 各最多 50 次，额外正文尝试共 8 次，搜索活动最多 90 秒；失败、重试、
  多 Key 和恢复不能重置额度。基础模型最多 12 次，补证复核最多 9 次，每轮最多 3 次实际尝试。
- 新建 Web 研究使用 `evidence-production-v8` / `native-research-kernel-v7` / `research-record-v2`。
  证据、字段资格、检查和数值收据按快照保存；新材料不能追溯改写旧输入。V1–V7 历史语义保留。
- Reader 与 Markdown 展示搜索过程、来源资格、恢复字段、专项复核和待查项。读取、刷新与重开
  保存记录不联网、不补跑模型。可通过有效配置 `evidence_search_enabled=false` 关闭新运行搜索。

## 正确性与降级

本次独立审查发现并修复五类问题：Tavily 日期缺失/格式适配，冲突后旧差值与增长率的失效，
后来取得的字段资格反向改变旧快照，Fetch/Extract 后转载的来源族归并，以及 PDF 网络错误与
检查点冲突的异常边界。新增只有 Tavily 可用的完整采集—准入—发布测试，以及三个受影响专项
共享每轮实际尝试上限的测试。可选来源失败保留已有资料；取消和完整性冲突仍中止执行。

## 保留边界与风险

自动字段恢复支持明确标注的身份/简介和已识别年报、半年报表中的收入、合并净利润、归母净利润、
经营现金流；其它排版、完整复权价格窗口和日期估值快照仍可能保留缺口。摘要不能替代原文，
字段资格不等于经济因果或投资结论。真实付费搜索的覆盖、延迟、成本和研究质量未作验收。

`npm audit` 仍有 **18 条既有开发链告警：4 moderate、12 high、2 critical**，完整审计不通过；
`npm audit --omit=dev` 为 **0 条**。锁文件依赖树未变，仅同步根版本。
critical 涉及 [Tinypool worker 原型污染](https://github.com/advisories/GHSA-5gmw-xhrv-c9v3) 和
[Vitest UI 文件访问/执行](https://github.com/advisories/GHSA-5xrq-8626-4rwp)。
沿用此前明确确认的处理方式：保持本次功能范围、记录风险，开发工具链升级作为独立事项。
预构建 Web 产品运行时不依赖 Node 测试/构建服务，但开发环境风险仍存在。
Vite 继续提示 minified chunk 超过 500 kB，未以提高阈值或关闭检查消除警告。

GitHub Release 表示源码分发，不表示已部署或运行中的本地服务已重启。
本次不迁移历史运行数据；分支、关联工作树和审查现场均保留，清场需最终汇报后的单独确认。
