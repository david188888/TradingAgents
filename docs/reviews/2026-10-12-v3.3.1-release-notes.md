# TradingAgents v3.3.1 — 研究检查、重试诊断与安装修复

Status: Release notes

Python 包、frontend package 与 lockfile 根版本统一为 3.3.1。
本次 GitHub Release 汇总 v3.3.0 之后的改动，提供 GitHub 自动生成的源码归档，不发布到 PyPI。

## 改进与修复

- **审计中心默认研究检查**：首先展示报告是否发布及其使用限制、失败位置与安全原因、资料缺口和各环节保存状态。SDK、预算授权、工具、配置与文件记录集中到独立“技术排查”入口，已有定向入口仍可用。
- **主面板聚焦研究内容**：环节详情移除执行统计与记录口径；保留真实保存的提议、研究正文、依据与未发布说明。
- **失败解释更明确**：对当前失败角色补充安全的字段、格式或依据引用校验原因；成功修复后的旧错误不显示为当前失败，不暴露原始模型回应与私密内容。
- **订阅传输错误分类**：ChatGPT 请求在未收到 Responses 数据且仍有整体时间预算时，连接失败或传输超时进入现有有限网络重试。收到数据后的断流、整体 deadline、权限/额度/能力错误和未知派发仍不自动重放。重试保留 2/5/10 秒、最多三次及每轮十二次模型尝试上限。
- **A 股＋Web 安装兼容**：默认 china extra 移除与现代 httpx 冲突的 mootdx 0.11.x；保留既有兼容安装的适配器及类型化不可用状态。使用已有 Conda 环境，不要求另建 venv。
- **a-stock-data v3.10.2 选择性审查**：固定 tag 的唯一计算修复是 PE 消化年数。本仓没有相应函数或消费者，因此更新审查与能力文档，不引入 30x 估值假设或无用代码。此前科创板成交量单位修复保留，详见 [审查记录](2026-10-12-a-stock-data-v3102-review.md)。
