# TradingAgents v3.6.0 — 事实前提、假设核查与离线输入对照

Status: Release notes

Python 包、frontend package 与 lockfile 根版本统一为 3.6.0。
发布渠道为 GitHub Release 与 GitHub 源码归档；不上传 PyPI 或额外安装包。
本版本交付已完成的研究契约及离线工具，不表示 V8／F01–F07 整改全部完成。

## 事实与核查链

- 新研究将代码拥有的观察、模型解释假设和待验证前提分开保存。
  观察与允许事实、来源、任务作用域及数值收据绑定，恢复、发布、Reader 和 Markdown 使用同一契约。
  修复最终 Agent 读取缺少 `factual_premise_policy` 身份校验的问题；身份不符时不附带前提解释正文。
- 重要挑战登记可核查性、所需输入及任务去向，可提出独立核查命题；原假设失效条件保持原意。
  当前可算、缺来源、工具不支持、未来观察、无法检验和执行失败分开表达，不靠缩小分母制造覆盖率。
- 新增有界财务明细字段和结构化财务比较。代码只核对合格保存输入；局部比较不冒充完整现金流桥，
  不将成功执行等同于经济风险消除。

## 综合与阅读

- 综合按分段校验、保留有效分段并定向修复失败部分；总体判断或关键挑战裁决未完成时不形成评级。
  主报告、阶段 Reader、相关依据及导出分别呈现保存产物和最终结果，历史缺字段明确保留未知。
- 新策略冻结在运行身份中；缺策略的历史记录保持原序列化、提示、收据和恢复语义，
  未知或被篡改的身份拒绝进入可信输出。
- 交易日历资格及日历来源限制、类型化执行错误与系统故障分类补充回归，避免将一般异常误写成缺配置。

## 离线输入与证据计量

- 新增 committed-run benchmark、只读 prompt 重建、阶段输入组成、未知用量及保守内容／作用域清单。
  这些工具在独立进程和内存副本中工作，不补跑模型、不改用户运行数据。
- 新增 `lossless-numeric-metadata-v1` 纯 codec 和完整 prompt 候选对照，逐项确认重复元数据后才共享表示。
  解码后的完整 JSON 必须等于原件；计入全部协议说明开销后，仅在净字节收益为正时采用离线候选。
  20 份保存输入均通过哈希核对和完整还原。历史派发账本样本减少约 4.89% UTF-8 字节，
  新契约合成样本减少约 5.83%；无净收益的样本保持原表示。
- **离线候选未接入生产提示词，未改变预算、预留、策略身份或恢复。** 字节减少不是 token、费用或质量改善。
