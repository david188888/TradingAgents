# TradingAgents v3.4.0 — 公司报告交付与局部缺口隔离

Status: Release notes

Python 包、frontend package 与 lockfile 根版本统一为 3.4.0。
沿用 GitHub Release 与源码归档渠道，不发布到 PyPI。

## 公司报告交付

- 公司公开介绍、基本财务与行情/量化观察组成可追溯基础报告，缺少 PDF
  明细、机构预测、个别指标或估值区间只限制对应章节。
- 新浪明确标签经证券/交易所核对；已保存官方报告中的明确主营业务和行业
  声明可以补充公司介绍。共享基础背景保持只读，专项引用仍按角色隔离。
- 综合复制的失效条件原文、回应 ID 与回应处理状态由代码恢复，真实事实引用
  继续校验；伪造依据与退出有效支撑的原观点仍被拒绝。
- 无法形成综合时交付已保存基础数据和有效专项汇总，明确综合阶段未完成，
  总体评级为 null，不制造 neutral 或 favorable。交付状态独立于分析覆盖。
- Reader 和 Markdown 同步显示基础资料、来源、局部缺口及交付状态。历史
  记录、提示哈希与恢复身份保持原样，取消/超时/持久化失败不使用此兜底。

## 引用与 A 股数据修复

- 专项经现有有限修复后可局部保留独立通过校验的假设，保存原索引与拒绝原因。
- 新策略允许带准确采集时点的当日行情，明确标注尚未结算；历史倍数序列
  保留自身日期。缺估值区间仍可形成有真实引用理由的谨慎判断。
- 引用错误诊断区分条件、维度、回应配对与论证绑定，不输出无效响应正文。
- 包含 v3.3.2 后已合入的无配额指数交易日历及估值核查修复（PR #28）。

## 验证与边界

发布前全量 Python 回归 3477 项、74 项子测试通过；现有 20 条测试警告保留。
357 项前端单元测试、2 项隔离浏览器端到端测试，以及 typecheck/build、Ruff、
132 页文档与差异检查通过。sdist/wheel 的干净提交快照构建结果另记于
GitHub Release；构建包仅用于验证，不上传为 Release 附件。

[江淮汽车验证记录](2026-10-13-company-report-delivery-validation.md)使用此前
真实冻结的资料生成独立离线预览，包含主营业务、行业、六项财务字段和七项
行情/历史统计观察。原始证据和历史报告哈希不变。
此前两次真实 Luna 全流程仍在综合阶段失败；本次修复后的新综合提示尚未进行
真实模型重跑。离线 mock 端到端通过不代表模型输出质量或预测准确率已验证。

GitHub 当前无 Actions workflow；没有配置检查不等于 CI 通过。发布不涉及
自动生产部署、其他项目、历史报告改写、分支清理或 Hindsight 操作。
