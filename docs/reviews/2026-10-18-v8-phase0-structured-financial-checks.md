## 结果与边界

新增“结构化财务基础覆盖”和“利润与现金流同期比较”两个独立子问题。它们可以在无 PDF
时使用合格的同供应商结构化三表通过核对；原经营披露完整性与完整现金流桥的范围、
状态和历史规则保留。净利润/CFO 两端点差额不冒充调节表组件，也不证明经济原因。

仅新建 V7 研究冻结 `structured_financial_policy=structured-financial-checks-v1`，产生
恰好五项、顺序固定且 ID 唯一的 calculation-v3 检查。历史 v2 仍重算原三项，v1 沿用
既有保存结果读取/挑战评估规则；旧提示中的检查枚举和恢复哈希不增加新选项。

独立从已披露结构化利润表/现金流表选最新季度截止期，与上年同月同日累计合并口径比较。
缺最新期字段不回退；不跨供应商拼单元格，重复期次与未来披露不填补缺口。
合并净利润与归母净利润分开；零/负基期保留金额差，不生成百分比增长率。
供应商冲突显式标记；可用官方单元格按原表精度互证，官方缺席单列限制。

新观察进入同一数值目录，锚点只要求实际计算需要的原始字段/期次事实。
例如 CFO 减合并净利润只绑定对应两项事实，不要求引用整家供应商的八期所有字段；
缺任一操作数时不允许数值模板通过。数值、方法、来源、范围与检查状态都经发布与读取重算。
Reader 正文及完整记录、来源面板、通俗指标解释与 Markdown 使用同一结果。
