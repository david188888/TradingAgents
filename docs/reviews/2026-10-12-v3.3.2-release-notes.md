# TradingAgents v3.3.2 — 证据引用修复与 Luna 综合验证

Status: Release notes

Python 包、frontend package 与 lockfile 根版本统一为 3.3.2。
发布渠道延续此前的 GitHub Release 与源码归档，不发布到 PyPI。

## 修复

- **条件引用提前校验**：V7 专项提议保存前，检查财务条件和指标依赖是否属于该假设的支持证据。失配进入现有有限结构修复；内核合并重复同一校验。条件绑定错误归为证据拒绝，避免误报配置缺失。
- **综合使用短代号**：新综合请求将保存的引用定义映射为确定性短代号，返回后精确还原原始 ID，再执行原有 schema、维度、回应与投资判断校验。缓存保存原始 ID；未知代号和跨维度引用仍被拒绝。
- **修复反馈明确绑定**：只重述冻结输入中的允许维度、条件或回应事实绑定，不回显无效响应。引用回应的论证必须使用该回应的事实，包括维持观点的回应。
- **历史恢复保持原样**：已有提示及修复提示保持哈希，未知派发不自动重放；整体时限、模型选择、预算、数据准入与发布屏障不变。

当前机制见[统一研究契约](../contracts/unified-company-research.md)、[研究操作](../operations/evidence-research.md)和[安全回放](../operations/observability-replay.md)。

## 真实验证与限制

官方 ChatGPT 订阅 `gpt-6-luna` 的最终冻结证据综合测试，在一次结构修复后通过原有公开记录校验，输出四个维度、一条支持理由、一条反对理由、两条裁决和三条原文失效条件。
它是独立综合验证，不是新的全流程成功研究。此前四次完整试跑均未取得有效综合；历史记录没有被改写。全部真实 SDK 调用为 32 次，详见[调查与验证记录](2026-10-12-600418-luna-validation.md)。
估值和市场数据缺口仍在，综合倾向仍为 `insufficient_evidence`；本次不生成合理价值区间，也不证明研究准确率。`budget_refused` 遮蔽前一次校验失败的 Reader 诊断问题、自由文本中的短质疑标签及 HTML 指南的视觉复核，仍未关闭。
