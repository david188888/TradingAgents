## Scope and non-goals

### In scope

1. Alpha Vantage daily-series trimming fails closed.
2. Query-string API keys are scrubbed from Alpha Vantage and FRED transport exceptions.
3. Model-visible dated tools cannot move beyond the run’s `trade_date`; omitted dates inherit the run date.
4. Insider transactions are bounded by the run date; current-only Wind risk metrics are withheld from historical runs.
5. Present-day instrument identity is labelled honestly in historical runs.
6. Yahoo provider failures are exceptions, not successful-looking report text, and outages are not asserted to be unknown symbols.
7. `clear_all_checkpoints()` removes SQLite WAL/SHM sidecars, including orphaned sidecars.
8. CLI-persisted `.env` credentials are owner-only on POSIX.
9. Focused tests, Ruff, docs check, and minimal project knowledge closeout.

### Explicitly out of scope

- No `git merge upstream/v0.5.0`, broad cherry-pick, or wholesale provider replacement.
- No SEC EDGAR implementation in this batch.
- No trading backtest, portfolio sizing, Trader/Risk/Portfolio Manager restoration, or product-boundary change.
- No change to the A-share vendor order or source semantics.
- No `load_ohlcv(fill_gaps=...)` port. The fork already drops incomplete rows without forward/back filling, and `tests/test_ohlcv_latest_bar.py::test_middle_incomplete_rows_are_dropped_not_filled` pins the safer local policy.
- No release, tag, push, or merge to `main`.
- No broad cleanup of every legacy provider string in one pass; only the confirmed Yahoo and Alpha/FRED paths below.

### Stop conditions requiring user confirmation

Pause before continuing if any of these occurs:

- The dedicated worktree cannot be created from a clean `main`, or the proposed branch/path already contains unrelated work.
- LangGraph does not hide a full-state `InjectedState` parameter from a model-visible schema in this installed version.
- Date clamping changes a deterministic prefetch bundle or Reader/package contract rather than only model-invoked tool arguments.
- Typed Yahoo failures change A-share fallback order, halt semantics, or evidence provenance.
- A focused regression test reveals that an upstream assumption conflicts with an intentional local contract not documented in the project map.

def _filter_csv_by_date_range(csv_data: str, start_date: str, end_date: str) -> str:
    if not csv_data or csv_data.strip() == "":

Implement in `dataflows/utils.py`:

```python
def get_scrubbed(
    url: str,
    *,
    params: dict,
    timeout: float,
    secret: str,
    passthrough: tuple[int, ...] = (),
):
    try:
        response = requests.get(url, params=params, timeout=timeout)
        if response.status_code not in passthrough:
            response.raise_for_status()
        return response
    except requests.RequestException as exc:
        message = str(exc).replace(secret, "***") if secret else str(exc)
        error = type(exc)(message)
    raise error
```

The raise remains outside the `except` block so `__context__` does not retain the original secret-bearing exception. Do not attach request/response objects to the replacement exception.
