# 双路搜索与研究中补证

Status: Current — 新建 Web `evidence_v1` 公司研究采用 `evidence-production-v8`、
`native-research-kernel-v7`、`research-record-v2`。历史身份保持原实现与原预算。

## 目的与分工

研究需要的是可核对的事实，不是搜索次数。专用接口适合带固定字段、单位和期次的数据；
搜索适合发现开放世界中的新闻、行业、政策与竞争材料。两路搜索合并材料后，只有仍影响
判断的具体缺口才触发后续搜索。搜索供应商负责发现，宿主负责准入、数值资格与预算。

`dataflows/search_sources.py` 在已有专用采集器上增加独立搜索协调器：

- 身份、简介、财务、行情、估值优先使用已配置的专用来源。
- 身份合格后，新闻、行业政策、竞争格局各产生一组 DeepSeek/Tavily 配对查询。
- 专用字段缺失时只查询缺失需求；身份恢复必须先得到唯一且明确的公司名称、上市日期与证券代码。
- 财务、简介、完整行情窗口或估值快照缺失时尝试定向搜索。搜到网页不等于该字段恢复成功。
- 搜索发现不使用静态域名白名单；新闻媒体和行业网站可以提供材料。来源资格由原文、日期、
  公司范围和用途决定。现有官方 PDF 表格解析器支持巨潮文档，其他排版保持待查。

例如财务接口返回收入但缺少经营现金流，宿主只提出该期经营现金流需求；新闻与行业
仍走双路搜索。网页只有“现金流明显改善”的文字时，可作为有出处的背景，不能补成现金流金额。

## 搜索、正文与数值资格

DeepSeek 使用独立 Search/Fetch API，不将搜索混入研究模型调用；Tavily 使用 Search/Extract。
默认 Tavily basic，不请求生成答案、不自动升级深度。查询绑定公司、证券代码、分析截止日，
DeepSeek 查询长度最多 128 Unicode 字符。端点、深度和准入策略冻结在运行身份中。

合并按规范化 URL 和内容处理同页、转载与截断材料，保留提取血缘与独立来源限制。
摘要和 snippet 只辅助发现；正文缺失、发布日期未知、超出截止日的内容不能进入合格事实。
历史分析仅接受可核对的不可变官方 PDF，不把今天的网页当作历史快照。

字段恢复要求证券代码、期次、单位、币种、会计口径或完整交易窗口符合原需求，并保存
原文哈希与定位。当前确定性解析支持明确标注的身份/简介，以及识别的年度、半年度合并
财务表中的营业收入、合并净利润、归母净利润与经营现金流。同比比较须来自同口径可比行。
其他排版、完整复权行情窗口及估值快照尚不自动恢复为可计算字段；搜索仍可提供背景资料，
未满足要求的数值继续缺失。冲突候选同时保留，不能用搜索静默覆盖专用接口数值。

正文请求校验公开地址并阻止访问私网；直接 PDF 下载限制 20 MiB，解析最多 500 页，
选取最多 12 页、每页 4000 字符。截断材料不能恢复数值。

## 执行顺序与共享上限

初始采集 → 三专项 → 一次独立挑战 → 宿主检查 → 被质疑专项回应 → 最多三轮补证与受影响
专项复核 → 一次最终综合。没有新增合格材料即停止；没有重跑的相关旧判断不能声称已更新。
原假设、条件及原回应保留，复核保存“维持、修正、撤回、无法回答”，综合读取当前适用性。

每家公司每次运行共享以下硬上限；它们是上限，不是必须消耗的目标。

| 池 | 上限与计数规则 |
| --- | --- |
| DeepSeek Search | 50 次实际请求，含失败和重试 |
| Tavily Search | 50 次实际请求，多个 Key 共用 |
| 额外正文获取 | 8 次 URL 尝试，Fetch、Extract、PDF 下载及重定向跳数共用 |
| 补证轮次 | 所有 Agent 共用 3 轮，每轮最多选择 3 个缺口 |
| 补证复核 | 每轮实际模型尝试 3 次，共 9 次；失败、重试和修复均计入 |
| 基础模型 | 12 次；与复核合计最多 21 次 |
| 专用数据 | 24 次能力调用、64 次 HTTP 尝试 |
| 全部数据 HTTP | 172 次，包含专用数据、搜索与正文池 |
| 搜索活动时间 | 90 秒；并发区间取并集，不计模型思考时间 |
| 整次研究 | 沿用 300 秒总截止时间；全局取消与截止优先 |

先原子预留，再发出请求。恢复继承消耗、缓存及输入绑定；已发出而结果未知的尝试按消耗
保守处理，不能以恢复或换 Key 重新获得额度。搜索重试至多一次；401/402 和安全拒绝等
不继续重试。一个供应商不可用时保留另一路结果；两路不可用、无新增、时间或预算用尽
均保存待查项和停止原因。全局取消不伪装成供应商失败。

## 保存、阅读与配置

`agents/schemas/_research_record_v2.py` 是新机器合同，`_search.py` 定义闭合搜索类型。
V2 最多 8 个追加快照：初始、原检查派生修订，以及三轮各自的材料/派生修订。
原快照、数值收据、检查历史可重放；新材料不追溯改写旧结论。V1 仍保持原双快照边界。
Reader/Markdown 展示搜索阶段、额度、来源资格、恢复字段、复核、待查项和停止原因；读取、
刷新、重开或切换历史记录均不联网、不调用模型。

在忽略的本地 `.env` 配置 `DEEPSEEK_API_KEY` 和 `TAVILY_API_KEY`，或已有的
`TAVILY_API_KEYS` 多 Key 配置。模型供应商可以独立选择，ChatGPT 登录不提供搜索服务凭据。
缺少一方凭据时降级；缺少双方时仍尝试专用接口，并保留搜索不可用说明。

有效配置 `evidence_search_enabled=false` 可关闭新运行的全部搜索与补证；仍保存 V2 记录
和明确的关闭原因。该值冻结在运行身份中，不能通过恢复重置预算或改变已保存请求。
`TRADINGAGENTS_EVIDENCE_ENABLED=false` 继续控制新研究创建；历史阅读不受影响。

## 验证范围

离线测试覆盖真实运行器、持久账本、恢复、发布、Reader 和导出，使用确定性供应商与模型
替身；Playwright 检查保存记录的桌面/窄屏展示与只读行为。离线通过不能证明真实检索覆盖、
研究质量、付费成本或生产延迟；这些需要另行授权有限真实样本验证。

接口参考：[DeepSeek Search/Fetch](https://api-docs.deepseek.com/zh-cn/guides/search/)、
[Tavily Search](https://docs.tavily.com/documentation/api-reference/endpoint/search)、
[Tavily Extract](https://docs.tavily.com/documentation/api-reference/endpoint/extract)。

字段资格另存首次生效快照（`qualification_snapshots`）；同一段原文后来才满足某个字段需求，
不能把该资格加进更早的数值目录、检查或模型收据。当前数值目录按完整有效输入筛选派生运算；
出现新冲突或比较基数失效时停用旧差值/增速，原快照仍可逐字段重放。
Tavily 显式请求日期并识别 ISO、RFC 邮件日期及仅日期的返回；仅日期按 A 股日历日比较，
保留日期精度和供应商估计标记，不声称取得了准确发布时间。
